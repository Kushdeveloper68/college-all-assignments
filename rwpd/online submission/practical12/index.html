Responsive Web Page Design (RWPD)

A subject covering HTML, CSS and the Bootstrap framework for building responsive websites.

Unit 1: Introduction to HTML

Important Topics: HTML document structure, tags, attributes, headings, paragraphs, links, images, lists, tables.

Key Points: Every HTML page starts with a doctype declaration and follows a tree structure of nested elements.

This unit builds the foundation needed before moving on to CSS and Bootstrap styling in later units.

Unit 2: CSS Fundamentals

Important Topics: Selectors, box model, colors, fonts, positioning, flexbox basics.

Key Points: CSS controls the visual presentation of HTML elements and can be applied inline, internally or externally.

Understanding the box model is essential for controlling spacing and layout on any webpage.

Unit 3: Getting Started with Bootstrap

Important Topics: Installing Bootstrap, container/row/column grid system, breakpoints.

Key Points: Bootstrap's 12 column grid makes it easy to build layouts that automatically adapt to different screen sizes.

This unit covers linking Bootstrap via CDN or local files and building the first responsive layout.

Unit 4: Bootstrap Components

Important Topics: Navbar, cards, buttons, alerts, forms, dropdowns, modals.

Key Points: Bootstrap provides pre-built, tested components that can be combined to quickly build a working interface.

Most components require both the Bootstrap CSS and the Bootstrap JavaScript bundle to work correctly.

Unit 5: Responsive Utilities and Plugins

Important Topics: Utility classes, responsive images and tables, JavaScript plugins like Scrollspy, Tooltip and Popover.

Key Points: Utility classes reduce the need for custom CSS, while plugins add interactivity like tabs, modals and tooltips.

This final unit ties together layout, components and interactivity to build a complete responsive website.
